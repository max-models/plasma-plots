# plasma-plots 0.1.1

## Features

- New `backend="tikz"`: every still plot can be drawn as TikZ/pgfplots code with LaTeX
  text, converted by [maxplotlib](https://github.com/max-models/maxplotlib). Save the
  result as `.tikz`, `.tex` or `.pdf` (compiled with `pdflatex`); see the
  [LaTeX figures guide](https://max-models.github.io/plasma-plots/guides/latex/).
- `plasma-plots plot` and `quicklook` pick `backend="tikz"` for a `.tex` or `.tikz`
  output. Animations and Plotly figures have no TikZ version and are reported as errors.

## Installation and optional dependencies

Requires Python **3.10+** (was 3.11+); CI covers Python **3.10 to 3.14**.

| New extra | Purpose |
| --- | --- |
| `tikz` | TikZ/pgfplots figures via `maxplotlibx>=0.2.0` (and `pdflatex` to compile) |

`tikz` cannot yet be installed together with `profiling` or `gallery`:
scope-profiler pins `maxplotlibx==0.1.9`.

[Documentation](https://max-models.github.io/plasma-plots/)
