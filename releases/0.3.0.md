# plasma-plots 0.3.0

## Features

- **Web figures**: `set_backend("plotly")` figures are saved as `.plotly.json` / `to_json(web=True)`
  for the docs theme, follow the theme's light and dark mode, and are shown in notebooks from
  `plasma_plots.figure` blocks. Captions for `plasma_plots.figure`, bars, polygon outlines,
  coordinate labels and page-sized text, and `imshow` images become Plotly heatmaps.
- **`set_math("latex")`**: a label with mathtext becomes one LaTeX formula in the Plotly
  conversion, HTML exports load MathJax when a figure has a formula, and unit exponents are
  written as superscripts (`W/m^3` -> W/m³).
- **`plot_domain`**: domains as drawings with their dimensions (boundary conditions, cell sizes,
  circles and spheres by diameter, radii, angles, hatches), also in TikZ.
- **Stellarator coils**: read CoilStellaration and ConStellaration coilsets and boundaries,
  draw coils in 3-D; `from_coilset` reverses the current of the mirrored coils as stellarator
  symmetry requires.
- **Instability diagnostics**: growth phase, dominant mode, the Penrose criterion and
  multi-species electrostatic growth.
- `plasma_plots.hero` for animated docs header figures, charts, phase space, geometry overlays and
  named styles, an `opacity` option for `slices_3d`, and `repeat_periodic` for full periodic plots.

## Documentation

- New guides for the charts, domain drawings and coils, interactive figures with dark variants and
  posters, MHD equilibria theory, and shorter page titles.

## Maintenance

- The `tikz` and `web` extras require maxplotlib 0.3; ruff replaces black and isort; the docs use
  the theme's major tag `v0`.
