# plasma-plots 0.2.4

## Features

- **Interactive 3-D scenes in notebooks**: `plasma_plots.scene(plotter, alt=..., title=...)`
  displays a PyVista plotter as a standalone vtk.js page plus a PNG screenshot, with the `alt`
  and `title` in the output's `"pyvista-scene"` metadata. Docs sites built from notebooks show
  the screenshot and load the scene on click. `.save_html(path)` and `.save_png(path)` write
  the two files. Needs the new `scene` extra: `pip install "plasma-plots[scene]"`.
- **Surface meshes**: `plasma_plots.pyvista_plots.pyvista_surfaces(meshes, ...)` draws PyVista
  meshes, `(vertices, faces)` arrays or simgeometry `SurfaceMesh`es in plasma-plots' style: one
  color per mesh with a legend of the labels, per-mesh `colors` and `opacity`, or coloring by
  `scalars` (a point-data array or a function of the points) on one color scale.

## Documentation

- The 3-D views guide shows interactive scenes in notebooks and a new "Surfaces and geometry"
  section. The docs' interactive scenes are exported with `plasma_plots.scene`.
