# plasma-plots 0.2.5

## Features

- **Point sets**: `plasma_plots.pyvista_plots.pyvista_points(points, ...)` draws labelled point
  sets, such as samples, grid nodes or crossings: `(n, 3)` or component-major `(3, n)` arrays
  (`(n, 2)` in the `z = 0` plane), a list of them or a dict by label. Each set gets a color from
  Matplotlib's cycle and a legend entry; `vectors=` adds an arrow at every point, e.g. normals,
  scaled by `vector_scale`, and `scalars=` colors the points by a value.
- **One legend per scene**: `pyvista_surfaces` and `pyvista_points` drawn into the same
  `plotter=` continue one color cycle and share one legend that lists every labelled surface
  and point set.
