# plasma-plots 0.2.5

## Features

- **Per-level isosurface colors and opacity**: `plot.isosurface` (and `pyvista_isosurface`)
  takes `opacity` and the new `colors` as one value or a list with one per level, e.g. an opaque
  surface inside a translucent shell. Explicit colors replace the scalar bar with a legend of
  the levels, named by the new `labels`. For 2-D fields they apply to the contour lines.

[Documentation](https://max-models.github.io/plasma-plots/)
