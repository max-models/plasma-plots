# plasma-plots 0.2.1

## Features

- **Rank boundaries on lineouts**: `plot_lineout` and `array.plasma.plot.lineout(...)` take
  `rank_boundaries` (a sequence of coordinate values) and `rank_boundary_color` (default red),
  drawing dashed vertical lines the same way `plot_slice`'s `overlays={"rank_boundaries": ...}`
  already did, so a 1-D profile of data split by [mpiarray](https://github.com/max-models/mpiarray)
  can mark its rank boundaries too.
- **`overlays={"rank_boundaries": ...}` takes an mpiarray `Layout` directly**, on `plot_slice`,
  `plot_panels`, `InteractiveSliceViewer`, `animate_slices` and `save_frames`: its axis for each
  drawn dimension is found by name among the plotted array's own dimensions (the sweep
  dimension excluded), so the layout needs no dimension names of its own and
  `Layout.boundary_values` no longer has to be called by hand. A plain `{name: values}` dict
  still works as before.
