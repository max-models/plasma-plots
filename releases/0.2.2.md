# plasma-plots 0.2.2

## Features

- **Convergence fits on the asymptotic range**: `plot_convergence` and
  `array.plasma.plot.convergence(...)` take `last=n`, which fits the order to the last `n`
  samples only, or, with `order`, draws the reference slope through the last sample over the
  last `n` samples. Use it when the coarse resolutions are not yet asymptotic.
- **Profiles by category, on log axes**: `array.plasma.plot.profiles(...)` takes `logx`, `logy`
  and `cmap`, and plots a categorical dimension (e.g. species) as one distinctly coloured line
  per category, in both the Matplotlib and Plotly backends. Dimensionless profiles are labeled
  without a unit.
