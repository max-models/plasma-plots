## What is plasma-plots?

`plasma-plots` registers a `.plasma` accessor on `xarray.DataArray` and
`xarray.Dataset`, and adds whole-run helpers for
[Struphy](https://github.com/struphy-hub/struphy) output, so you can go from a
saved simulation to a figure in one line:

```python
from struphy.post_processing.output import Output

out = Output("path/to/run")
out.evaluate("em_fields/phi").plasma.plot.slice(x="eta1", y="eta2", t=-1)
```

:::note[Loaded by Struphy]
Creating a Struphy `Output` loads plasma-plots. For xarray data from
elsewhere, `import plasma_plots` first; without it, `.plasma` raises
`AttributeError: 'DataArray' object has no attribute 'plasma'`.
:::

:::tip[Output of other codes]
plasma-plots reads labeled arrays, not Struphy files: arrays from any code work
when their dimensions and coordinates follow the same names (`t`,
`eta1`/`eta2`/`eta3`, `X`/`Y`/`Z`, `marker`). See
[Data from other codes](/plasma-plots/guides/getting-started/#data-from-other-codes).
:::

## Looking for a simulation to plot?

`plasma-plots` plots data recorded by simulations such as
[Struphy](https://github.com/struphy-hub/struphy)'s; it doesn't run any physics itself. If you want simulations to
generate output from:

- **[Struphy's examples gallery](https://struphy-hub.github.io/examples/)** —
  Landau damping, the Orszag–Tang vortex, bump-on-tail, and dozens more,
  each with the model, domain, and parameters that produced it.
- **[MHD slab waves](/plasma-plots/guides/real-example/)** — every figure
  on that page comes from an actual Struphy run, reproduced by this repo's
  own docs build.
- **[Struphy's own documentation](https://struphy-hub.github.io/)** — models,
  propagators, domains, and everything else plasma-plots reads output from.
