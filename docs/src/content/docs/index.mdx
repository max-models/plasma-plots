## What is struphy-plots?

`struphy-plots` registers a `.struphy` accessor on `xarray.DataArray` and adds
whole-run helpers for [Struphy](https://github.com/struphy-hub/struphy)
output, so you can go from a saved simulation to a figure in one line:

```python
out.evaluate("em_fields/phi").struphy.plot.slice(x="e1", y="e2", t="last")
```

## Looking for a simulation to plot?

`struphy-plots` plots data recorded by [Struphy](https://github.com/struphy-hub/struphy)
simulations; it doesn't run any physics itself. If you want simulations to
generate output from:

- **[Struphy's examples gallery](https://struphy-hub.github.io/examples/)** —
  Landau damping, the Orszag–Tang vortex, bump-on-tail, and dozens more,
  each with the model, domain, and parameters that produced it.
- **[A real simulation](/struphy-plots/guides/real-example/)** — every figure
  on that page comes from an actual Struphy run, reproduced by this repo's
  own docs build.
- **[Struphy's own documentation](https://struphy-hub.github.io/)** — models,
  propagators, domains, and everything else struphy-plots reads output from.
