## What is struphy-plots?

`struphy-plots` registers a `.struphy` accessor on `xarray.DataArray` and adds
whole-run helpers for [Struphy](https://github.com/struphy-hub/struphy)
output, so you can go from a saved simulation to a figure in one line:

```python
out.evaluate("em_fields/phi").struphy.plot.slice(x="e1", y="e2", t="last")
```
