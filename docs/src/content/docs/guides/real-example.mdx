Every other guide in these docs builds small, synthetic `xarray` data by hand, so the site
can be built quickly and without a struphy install — the point there is `struphy_plots`
itself, not any particular physics. This page is the one exception: both figures below come
from actually running struphy, adapted from
[struphy's own gallery example](https://struphy-hub.github.io/examples/mhd-slab-waves/), to
show the same functions working end-to-end on genuine output. The full code is below,
unedited.

## The physics

`struphy.models.LinearMHD`, in a uniform, obliquely magnetized plasma
(`struphy.fields_background.equils.HomogenSlab`, background field `B0 = (0, 1, 1)`).
Broadband noise in the velocity excites every MHD wave branch along z at once: the shear
Alfvén wave, and the slow and fast magnetosonic waves. Their exact ideal-MHD speeds follow
from the background alone; comparing them against the speeds actually measured from the
run's own output is the point of the two figures below.

## The magnetosonic branches

The same, for the pressure field: both the slow and fast magnetosonic branches appear in one
spectrum, so both get a `branches` entry. The fast branch's ridge is clean; the slow one is
noisier — a 64-element grid resolves a handful of `k` values, and the slow branch's smaller
slope leaves less separation between it and everything else near `k = 0`. That's an honest
resolution limit, not a plotting bug.
