Every other guide in these docs builds small, synthetic `xarray` data by hand, so the site
can be built quickly and without a struphy install — the point there is `struphy_plots`
itself, not any particular physics. This page is the one exception: every figure below comes
from actually running struphy (see `scripts/generate_real_example_figures.py`), to show the
same functions working end-to-end on genuine output.

Reproducing it locally needs the full compiled struphy runtime (the `struphy` git submodule
in this repo, plus `struphy compile -y`) — see
[CONTRIBUTING.md](https://github.com/struphy-hub/struphy-plots/blob/devel/CONTRIBUTING.md).

## A real convergence study
