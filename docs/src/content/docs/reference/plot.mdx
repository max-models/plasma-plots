Plots of one labeled `xarray.DataArray`, as `array.struphy.plot.<method>(...)`. Each method selects the dimensions it doesn't draw by keyword (an integer is a position, `t=-1` the last; a float the nearest value), draws, and returns a `PlotResult` (or an animation or a PyVista plotter).

:::note[Where the accessors come from]
The examples use output of a Struphy `Output`, which loads struphy-plots and its
`.struphy` accessors. For other xarray data, run `import struphy_plots` first (see
[Getting started](/struphy-plots/guides/getting-started/#loading-struphy-plots)).
:::
