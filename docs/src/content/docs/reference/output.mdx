Plots and diagnostics of a whole run, on a Struphy `Output` object: `out.plot` (with `out.plot.profile` for timing data) and `out.analysis`.

The methods are listed alphabetically below. For a contents list of every method, see the [`output_accessors` module page](/struphy-plots/api/struphy_plots/output_accessors/#struphy_plots.output_accessors.OutputPlots).

:::note[Where the accessors come from]
The examples use output of a Struphy `Output`, which loads struphy-plots and its
`.struphy` accessors. For other xarray data, run `import struphy_plots` first (see
[Getting started](/struphy-plots/guides/getting-started/#loading-struphy-plots)).
:::
