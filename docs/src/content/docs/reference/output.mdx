Plots and diagnostics of a whole run, on a Struphy `Output` object. `out.plot()` on its own draws the scalar overview.

:::note[Where the accessors come from]
The examples use output of a Struphy `Output`, which loads plasma-plots and its
`.plasma` accessors. For other xarray data, run `import plasma_plots` first (see
[Getting started](/plasma-plots/guides/getting-started/#loading-plasma-plots)).
:::
