# constellaration_boundary.json

A plasma boundary in ConStellaration's `boundary.json` layout (four field periods, stellarator
symmetric), the example input of the ConStellaration benchmark, copied unchanged from
`hugging_face_competition/inputs/boundary.json` of
https://github.com/proximafusion/constellaration at commit
e9b43f643096c7c3949386e725d43e5f00f555f1. `scripts/generate_coil_figures.py` draws it in the
"Stellarator coils" guide.
